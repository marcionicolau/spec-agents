# PCA interpretation examples

**Soil fertility (5 variables, 120 plots).** PC1 explains 38% of the variance: N, P and organic matter
load positively, so it is a *fertility gradient*. PC2 explains 22%: pH loads positively and K negatively,
so it is an *acidity/potassium contrast*. Together they retain 60%. Bartlett p < 0.001 and KMO = 0.71,
so the structure is adequate.

**Weak structure.** Bartlett p = 0.52 and KMO = 0.46: the variables are nearly independent. Report
the PCA as uninformative and analyse the variables separately.

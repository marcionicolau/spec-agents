A small, dependency-free pack: components `text_stats` and `keywords` and the pipeline `document_digest`. It proves the core is domain-agnostic and is the smallest template for a new pack.

## Install

```bash
pip install spec-agents-text
```

## Example

This is the same script as step 1 of the [Quickstart](../quickstart.mdx): build a registry from the pack's `register`, instantiate the pipeline with parameters, validate the plan, run it.
